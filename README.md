# Club Social y Deportivo Les Molestes

Toda la historia de Les Molestes (fútbol amateur): partidos, goles, jugadores, rivales, torneos, títulos, fotos y videos de goles.

**App:** https://renesps.github.io/les-molestes/

Web app estática (Vite + React + TypeScript), instalable en el celular y con modo sin conexión. Las guías están en [`docs/`](docs/LEEME.md).
